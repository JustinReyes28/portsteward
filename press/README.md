## Publishing notes
Copy only the draft body or numbered thread post you intend to use. Post as the builder; the copy uses first person for that reason. All repository and issue links point to this project. No social post has been submitted.

Use one relevant Reddit destination first. The drafts are written for different audiences; do not paste the same announcement across communities. Check the destination's current rules, promotion threads and flair before submitting. These drafts do not assert that any community currently permits promotion.

Keep the Windows alpha status, run-from-source requirement and process-control limitations in the conversation. There is no npm package or versioned GitHub release to link yet. The repository is public source; that does not mean phase 4 beta validation is complete.

For demo media, use the included sample projects, confirm the shown action and record the result. The demo script does not turn simulated output into live evidence. Do not include personal project paths, private commands or unrelated process details in a recording.
